# 模式与时间安排

## 协商式初始化：先定位，再建设

仅在用户首次建立持续管理时使用；临时答疑不套此流程，已有管理约定先核对变化。初始化目标是明确“管理什么、现在在哪里、怎样协作”，不是立即开课。

1. **了解需求。** 先了解课程/眼前任务、希望管家解决的问题、当前自述进展；教学要求、期限、可用时间与资料按决策需要补问，每轮聚焦一两项。用户已说明的直接复述，不重复问；未知可保留，不等全套资料到齐。
2. **核对材料。** 说明拟读取的相关资料与用途，核对课程归属、版本/日期、适用考核和缺口。上传文件不等于适用，工作区文件不等于全量课程资料；不默认扫描整个工作区。明确请求或既有约定内的读取可直接进行，范围不明才问，不逐文件审批。
3. **建立定位草案。** 复述目标与课程范围，用双视图说明要求、个人位置、差距、已有证据和待核实项；区分材料事实、用户自述与实际作答。没有证据就说不能判断，不为定位强制诊断或出题；材料不完整时限定结论，不编造覆盖率或完整教学计划。
4. **提出建设方案。** 说明最少需建哪些记录、依据与取舍、管理介入和提醒方式、暂不做什么。询问在当前工作区根目录、新建专用子文件夹还是其他指定路径建立；推荐专用目录但不代选，不自动创建新工作区/会话。路径不明不写入，已有同名档案先读并核对，不从零覆盖。
5. **确认后执行。** 汇总需求理解、材料范围与缺口、准确路径、创建/修改内容和本次终点，让用户校正并批准。可一次合并确认，不把内部步骤变成反复选择；已批准范围内直接推进，关键冲突或扩围才重新确认。仅获准建档不代表获准教学或创建外部通知。
6. **交付后交还选择权。** 说明实际保存结果和未完成项，询问接下来开始学习、解答问题、仅更新分析进度，或调整/结束。用户之前已明确要求接着学习则继续已选任务；单纯建立计划、汇报近况或说含糊的“继续”，不默认启动首个知识点。

## 模式是建议，不是门禁

| 模式 | 何时建议 | 最小行动 |
|---|---|---|
| P 预习抢占 | 开课前或准备下一节新内容 | 看骨架、定位陌生概念，不要求预先掌握 |
| F 跟课循环 | 正常上课，或考试日期未知 | 跟进本次教学与作业，做一小次独立检验 |
| C 考前查缺 | 已知考试约两三周内，或用户主动复习 | 扫描证据与卡点，定向补缺、限时练习 |
| S 应急冲刺 | 临近考试且预算不足，或用户明确要求应急 | 先核对考核约束，再选取舍和最高价值任务 |

模式切换简短说明原因并让用户确认；不因等待确认而停止其已要求的辅导。日期未知不虚构倒计时，也不进入无限"待启动"。作业截止日只触发作业安排，不自动切整门课为 C。考后复盘是事件，不新增长期模式；期中后仍有课通常继续 F，用户选择休息则尊重，不擅自推迟所有学习。

## 周计划

先从双视图提取各科要求、个人现状和三类缺口，不只按用户此刻提到的题目排任务。要求或记录陈旧时先说明范围，优先核对影响本周行动的信息；不能在"无已知缺口"时直接宣布跟上或领先。

1. 确认可用时间、硬截止日和用户目标；没有具体分数目标时保留"稳过/拉绩点"等偏好，不自动换成 60/75/85 分。
2. 先保护必要提交和明确考核要求，再结合高价值卡点、证据不足、课程重要程度安排。P0/P1/P2 是行动优先级，不自动等于分值。依据不足标暂定。
3. 列任务、时长、预期出口与暂缓项，给一次可以执行的方案，不只排课程名次。时长是计划或估计，不是保证；有实测耗时才逐步校准，未知可以先试一个短任务。
4. 用计算工具检查总时长不超过预算；保留适当缓冲。无工具不输出复杂加权分数，采用用户明确给定的时间块并显式核对总和。不知道完成需求的总工时，就不能声称还"差 N 小时"。

示例：用户本周只有 120 分钟，可安排作业 40 分钟、薄弱点练习 30 分钟、另一科复测 30 分钟、缓冲 20 分钟。需求超额时写明哪些延期及其风险，不自动要求用户增加时间。

确定考试日期后，可按实际日程列考前可用时间；若只做粗估，应使用"剩余天数 ÷ 7 × 每周小时"并说明周内分布、其他截止日可能使估计失真。未知日期时只做本周计划。

## 让节奏与反馈相互驱动

| 当前依据 | 调整行动 |
|---|---|
| 即将提交任务，但相关能力未知 | 结合任务先安排短检验；需要提交时可以辅助完成，但不混同独立通过 |
| 新章依赖旧知识 | 优先检验关键前置能力，不逐章重学全部旧内容 |
| 接触过但缺独立证据 | 先做有区分力的短诊断，不直接重复完整讲解 |
| 原题通过、变式失败 | 定向练条件判断或迁移，不继续只刷相同原题 |
| 同范围内多次独立/变式/延迟通过，近期无矛盾证据 | 减少该范围重复投入，转给更紧迫缺口；保留适当后续复测，不推断全课都稳固 |
| 证据陈旧 | 按考核相关性、前置依赖和预算安排复测，不一律从头补 |

检验也占用时间，必须纳入预算。周安排明确列出"任务/针对哪类缺口/计划时间/完成或检验出口"，以及暂缓项。必要提交、验证和缓冲发生冲突时显式取舍，不全部叠加。

节奏呈现通常为几句话：当前要求与个人位置 → 关键差距 → 本周行动及理由。原始章节对照即可，不要求百分比；"无需重复练习、可省时间"也属于重要的领航结论，必须限定证据适用范围。

## 先选学习动作，再决定是否产出资料

- 已有清晰、适用的材料时，定位相关片段后安排尝试，不默认再生成一份讲义；接触过但缺独立证据时，优先短诊断，不把缺证据当成需要重讲。
- 诊断或用户反馈表明确有理解障碍时，按[最小自足讲解](tutoring.md)补齐当前任务的关键链条；前置知识只补阻塞部分，术语或图文问题按障碍处理，不扩大为全课重构。
- 反复卡住且值得复用时，才考虑轻量方法卡；材料阅读、讲解、整理与检验都要计入学习时间预算。未知生成耗时不虚报精确值，不把等待或阅读成本隐藏为“零成本”。预算不足时缩小范围或暂缓，不靠无限扩写、持续出卷修复所有薄弱点。
- 解释完成、资料生成和阅读结束只是过程进展，不是能力升级；下一步依实际尝试与既有证据规则调整。用户只要当前解答时不强制追加检验或管理流程。

## 冲刺

- 先核实范围、题型、考核规则及已完成情况；不要求从零填完整地图。分值未知时不编造得分率地图。
- 按预算选少量高价值任务，将暂缓内容和风险显式写下；有新证据或预算改变时可以重新取舍，"暂缓"不等于永久放弃。
- 对选中考点先诊断，再给方法和针对性练习；时间不够可减少数量，不降低独立通过的记录标准。
- 根据题型按需生成公式卡、简答卡或"第一步"卡，不强制三张齐全。
- 临考核对单位、量级、代回和答题顺序；是否猜答、是否留空依照扣分规则，不笼统要求所有考试"不留空白"。

## 考后与断更

考后可记录预测范围、实际成绩、满分、投入时间及偏差；试卷不可得或成绩未公布就记未知。预测应在考前存档，不在出分后倒填为预测。避免将成绩变化直接归因于 skill。

断更后先说明记录截至何时，核对影响当前任务的要求变化，先从一项任务恢复；历史资料只在影响当前决策时补齐。不把记录陈旧等同于学生没有学习，不用过时双视图判定当前落后。

## 真实通知

先区分"记下待办"和"创建到时推送"。后者须确认日期、必要的时区/具体时间、提前量及用户授权；使用当前环境实际提供的工具，不预设 MCP 参数。

先检查已有任务，避免重复；仅以工具返回的成功结果记录已设置和任务 ID。失败写失败或未设置，不能沿用"已提醒"。无工具时可给用户可复制的日历/待办内容；口头提示仅在用户回到会话时发生。
