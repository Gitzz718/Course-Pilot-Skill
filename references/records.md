# 数据口径与模板

## 最小化记录

临时答疑不强制建档；持续跟踪时建立"当前情况"和双视图，有关事实缺失标未知，不阻塞学习。其余部分有内容再扩展，下列不是要求用户填满的问卷。跨科需要时再建总览，需留场景时再建用户场景库。数据与技能安装目录分离。

```text
course-pilot-data/
  _总览.md
  <课程名>/course-state.md
  SCENARIOS.md
  _规则覆盖.md
```

从自由文本提取课程、日期、教学位置、卡点、作业和期限、考试信息；只记录实际出现的信息。一段涉及多科则分科，不能确定归属的条目先暂存并询问。区分发生日期与记录日期；"下周五"等相对时间按用户日期与时区解析，存在歧义先确认，不能用助手宿主日期替代。

## 可选管理约定

持续管理初始化先在聊天提出草案，用户确认范围与路径后才保存。管理约定仅记录影响行为的偏好：管理目标与课程范围、希望介入的程度、主动提示/提醒的边界、汇报方式、可读取的资料范围、保存位置与授权。采用用户原话，未约定标未约定；不把建议任务当成用户承诺，不要求填满字段。

课程特定约定附于该科“当前情况”，跨科共用约定按需附于已有总览，不新建第二套档案或默认复制每科；明确拍板的覆盖规则才进入个人覆盖层。材料适用范围、版本与缺口复用“考核情报与资源”；可在资料不足时保存最小框架，但不得声称资料齐全或能力已确定。

## 双视图及更新口径

持续跟踪中，双视图是稳定维护的摘要，不是重复台账；引用课程内的要求记录、任务和证据ID。有相关变化才刷新，用户请求定位时即使无变化也应明确现状。字段允许未知，不强行追问填满。需要的最小操作顺序：读相关记录 → 提取新增事实/证据 → 更新受影响视图与行动 → 按入口规则简述；涉及跨科安排或总览已有对应行时同步更新总览。

**节奏视图：** 当前要求、个人现状、具体差距、本周行动。比较同一课程范围和有效日期，分别列：

- 教学跟进缺口：老师已讲、用户尚未跟进；用户没汇报的部分只能记"跟进情况未知"。
- 任务缺口：应完成但尚未完成的作业/提交；区分未到期、临期、逾期，不将所有未完成叫拖欠。
- 能力验证缺口：相关内容接触过或任务完成，但缺乏所需独立证据；未检验不等于不会。

**反馈视图：** 当前证据、本次变化、仍不稳定之处、下一次检验内容/建议时机。摘要须覆盖会影响当前判断的近期失败，不能仅保留最高标签。"进步/退步"须有可比较的任务、条件与证据；不可比时描述差异而非断言变化。

最近近况日期反映对课程安排和用户活动的了解，最近独立检验日期反映能力判断依据，两者分别记录。天天汇报不自动刷新证据日期，记录陈旧不等于学生未学习。未知教学要求时仍可给反馈，但节奏对照须明确受限；不据旧记录直接断言现在落后。

节奏示例：老师已到第四章，用户自报跟进到第三章；第四章作业周五交。当前有第四章跟进和任务缺口，第三章独立证据未知。本周先跟进第四章并完成作业，之后检验第三章。这里没有理由称第三章"不会"。

## 情报与冲突

- 为影响安排的信息保留来源、记录时间、适用考核和确认状态。用户转述就注明转述，不冒充已核查通知。
- 明确的新正式更正可替代旧安排，并保留"替代了什么、依据是什么"的日志；不能仅按新旧时间选真。
- 先检查是不是不同考核、不同作业或不同适用范围。仍有重要冲突则列旧/新及来源与日期，询问可核实的材料，不要求用户凭回忆强行裁决。
- 未解决就保留两种说法，不覆盖；可暂按较早期限准备但标为保守计划，不能当成已确认事实，更不能据此擅自创建外部通知。

## 按需材料范围与方法卡

- 多文件、多个版本或考试范围影响当前决策时，在已有“考核情报与资源”中补记本次纳入/排除范围、关键来源位置、版本或日期、适用考核及缺失内容；未知标未知。单题直接使用已有题面，不先要求完整材料清单，不新增必填台账。
- 可区分材料原文、用户转述、自行推导和 AI 补充；来源定位到实际读到的文件/页码/题号或片段，不能编造页码。未读取的文件不记为已覆盖，未解决的版本冲突沿用上节处理。
- 反复卡住、有复用价值或用户要求时，可把已讲内容整理为轻量方法卡：适用任务与条件、关键步骤、必要符号、典型题源、易错点和下一次检验。字段按需，不为单题默认建卡或重写教材；优先在聊天呈现，保存仍遵守既有授权与位置约定。
- 方法卡引用课程内的知识点/证据 ID 与来源，不再维护第二套掌握度；补充解释不是新作答证据。修改方法卡时仅更新相关资源索引，不要求每次反馈同步所有卡片，不自动建立跨课程背景档案。

## 可展示的指标

| 项目 | 口径/限制 |
|---|---|
| 教学位置 | 原始章节/课次和来源日期，不自动换为掌握率 |
| 独立检验覆盖 | 有独立通过证据的知识点数 / 已列知识点数；仅反映该版地图，须披露地图是否完整及近期失败 |
| 分值覆盖 | 只有明确权重、覆盖范围且已消除重复计分时才可汇总；这是题目范围映射，不是预测实际得分 |
| 待复测 | 按最近独立证据与约定复测间隔列出 ID；不运行后台扫描 |
| 落后 | 有同口径的教学计划与学生完成记录才比较；否则列缺口条目，不造"落后两周" |
| 计划时长 | 预算内分配；与实际耗时、预计总需求分开 |

汇总保留计入的知识点 ID、分子分母、日期和口径。工具不可用时展示原始条目而不是复杂派生值。知识点地图增删需记录版本变化，不能把分母改变解释成学生退步。

## 场景与纯聊天接续

用户场景记录只需：编号、日期、触发、实际处理、观察结果、是否同意公开。记录许可不等于公开许可。公共案例另存于维护材料，公开前还须检查身份、路径、成绩、题目版权等。

纯聊天接续摘要保留：课程/任务、用户目标、要求与现状及来源日期、具体缺口、最新证据与变化及卡点、下次检验及建议时机、明确期限、未解冲突、下一步及理由。标明"仅为本次会话摘要，未写入文件"，让用户下次带回；不要输出所有空模板。

## 从 v1.0 迁移

仅在用户要求迁移时进行，先保留原档，不批量覆盖。旧"会用"没有题目、日期、提示记录时标"历史自报，待复核"；旧"卡住"移入当前卡点。无法复算的百分比不沿用为新指标，原值留在历史记录。原题干索引、资源、通知 ID 与情报来源保留；没有通知成功凭据的条目标记"设置情况待核实"。不补造历史数据。
